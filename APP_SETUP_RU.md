# Настройка Meshtastic App

## Что выбрать в приложении

Если приложение спросит регион, выбирай:

```text
EU_433
```

Не выбирай `RU`: в Meshtastic регион `RU` работает в районе 868 MHz, а модуль Ra-02 у нас 433 MHz.

## LoRa settings

Оставь так:

```text
Region: EU_433
Modem Preset: Long Fast
Frequency Slot: default / 3
Hop Limit: 3
TX Enabled: On
```

Регион также принудительно зашит в прошивку, поэтому даже если приложение показывает странно, лог устройства должен оставаться на 433.875 MHz.

## Канал

На обоих устройствах должен быть один и тот же Primary Channel:

```text
Channel name: LongFast
PSK: default
```

Самый надежный способ:

1. Подключись приложением к первой плате.
2. Открой Channels.
3. Сделай Share / QR для Primary Channel.
4. Импортируй этот канал на втором устройстве.

## Проверка связи

1. Подключись к первому модулю.
2. Отправь сообщение в Primary Channel.
3. Подключись ко второму модулю.
4. Проверь вкладку Messages и Nodes.

Если узлы не видят друг друга, проверяем в Serial Monitor обе платы: должны быть `EU_433`, `433.875` и `RF95 init success`.
